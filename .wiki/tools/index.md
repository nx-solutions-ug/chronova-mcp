# Files

- [get_ai_insights](get-ai-insights.md) - AI-assisted vs manual coding analytics: adoption timeline, contribution share, language matrix, project AI-dependency, and efficiency trend.
- [get_developer_context](get-developer-context.md) - Returns the authenticated user's Chronova profile, subscription, GitHub integration status, and organization memberships.
- [get_productivity_summary](get-productivity-summary.md) - Aggregated coding productivity statistics (totals, language/editor/project/OS breakdowns, daily and hourly stats) for a time range.
- [get_recent_activity](get-recent-activity.md) - Paginated list of raw coding heartbeats (activity events) with optional filters by date, project, language, editor, and pagination.
